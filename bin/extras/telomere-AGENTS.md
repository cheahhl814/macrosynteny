# Telomeric Repeat Data — AI Agent Guide

## Source

Generated by `telomere_to_json.py` from tidkFind TSV output. The TSV contains per-window counts of telomeric repeat in forward and reverse orientations across 10 kb windows of each scaffold.

## JSON Schema

```json
{
  "metadata": {
    "source_file": "",
    "num_scaffolds": ,
    "telomere_threshold": 
  },
  "scaffolds": [
    {
      "scaffold_id": "",
      "scaffold_length_bp": ,
      "window_size_bp": ,
      "num_windows": ,
      "telomeric_repeat": "",
      "telomere_signal": {
        "detected": {true/false},
        "threshold_used": 100,
        "start_region": {
          "windows_checked": ,
          "max_total": ,
          "enriched": {true/false}
        },
        "end_region": {
          "windows_checked": ,
          "max_total": ,
          "enriched": {true/false}
        }
      }
    }
  ]
}
```

## Field Descriptions

| Field                | Type    | Description                                    |
| -------------------- | ------- | ---------------------------------------------- |
| `scaffold_id`        | string  | Full scaffold identifier from the assembly     |
| `scaffold_length_bp` | integer | Approximate length in bp (max window position) |
| `window_size_bp`     | integer | Window step size (typically 10,000)            |
| `num_windows`        | integer | Number of windows for this scaffold            |
| `telomeric_repeat`   | string  | The repeat motif searched for                  |
| `telomere_signal`    | object  | Telomere enrichment assessment (see below)     |

### telomere_signal

| Field                          | Type    | Description                                            |
| ------------------------------ | ------- | ------------------------------------------------------ |
| `detected`                     | boolean | True if start or end region has max_total >= threshold |
| `threshold_used`               | integer | Copy-number threshold for enrichment (default 100)     |
| `start_region.enriched`        | boolean | First N windows contain a strong telomere signal       |
| `start_region.max_total`       | integer | Maximum total repeats in any of the first N windows    |
| `start_region.windows_checked` | integer | Number of windows inspected at the start               |
| `end_region.enriched`          | boolean | Last N windows contain a strong telomere signal        |
| `end_region.max_total`         | integer | Maximum total repeats in any of the last N windows     |
| `end_region.windows_checked`   | integer | Number of windows inspected at the end                 |

## Interpretation Guide

### Telomere Detection Logic

- The first and last 10 windows of each scaffold are examined.
- If **any** of those windows has `total_repeats` (forward + reverse) >= 100, that end is flagged as enriched.
- The threshold of 100 is conservative: vertebrate telomeres in 10 kb windows typically reach 100–200+ copies, while internal repeats stay near zero.

### Common Patterns

| Pattern                                        | Interpretation                                                                  |
| ---------------------------------------------- | ------------------------------------------------------------------------------- |
| Both ends enriched                             | Strong candidate for a complete chromosome with telomeres at both ends (T2T)    |
| One end enriched                               | Possible chromosome end; the other end may be incomplete or centromere-proximal |
| Neither end enriched, internal repeats present | Probable interstitial telomeric repeats (ITSs) or repeat-rich region            |
| Neither end enriched, no repeats               | No telomeric signal detected                                                    |

### Usage Notes

- Scaffolds are sorted by length descending.
- Small scaffolds (< 50 kb) may lack windows to assess at both ends.
- This is an aggregated summary; raw per-window detail is in the source TSV if finer resolution is needed.
